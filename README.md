## Description

Original: Adds several rectangular platforms. The blob is drawn as a noisy circle but collides using a simple axis-aligned bounding box (AABB). X and Y are resolved separately to keep behaviour predictable and teachable.

- This project lets users control the blog and jump around the screen. It is meant to express anxiousness with its erratic movement and environment
- My edits: Added and moved around platforms from the original setup, also changed the blob's movement speed to be more erratic.

---
## Interaction Instructions
- Use the up down left right or WASD keys to control the blob movements

Example:
> Press the up key to jump
